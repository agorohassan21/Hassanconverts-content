# hassanconverts-content

Approved carousels for @hassanconverts. Buffer pulls the images from here when a post goes out.
Only posts Hassan has approved are added.

## Keep a copy forever

Everything in this repo belongs to your GitHub account (agorohassan21), not to Claude.
It stays here even if a subscription ends.

1. Open github.com/agorohassan21/Hassanconverts-content
2. Tap the green **Code** button
3. Tap **Download ZIP**

## What's inside

**media/v2/** holds one folder per carousel (for example d01a). Inside: the slides as JPGs, 1080 by 1350, plus the PDF used for LinkedIn.

**captions/** holds one text file per carousel: the Instagram caption, the LinkedIn caption and the post time.

**manifest_w1.json** is the posting plan Buffer was loaded from.

Posts already scheduled in Buffer keep publishing on their own. Buffer does not depend on Claude.
